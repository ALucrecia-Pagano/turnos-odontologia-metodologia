Fecha: 2026-11-08
Repo: turnos-odontologia
Objetivo: instalar la skill oficial `skill-creator` a nivel proyecto, versionarla en `.agents/skills/` y verificar que las copias son idénticas.

---

## 1. Instalación a nivel proyecto

Comando solicitado:

```
npx skills add anthropics/skills --skill skill-creator -a claude-code --copy
```

Nota: sin `--yes`, el CLI queda esperando el prompt interactivo "Installation scope" y no instala en un entorno sin TTY. Se reejecutó con `--yes` (opción recomendada por el propio CLI: "use the --yes (-y) ... flags to install without prompts"):

```
npx skills add anthropics/skills --skill skill-creator -a claude-code --copy --yes
```
